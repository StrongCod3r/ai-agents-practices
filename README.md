# Prácticas con agentes de IA

Colección de proyectos educativos en C# y .NET 10 para practicar el uso de herramientas, la consulta de servicios externos y la memoria persistente en agentes de IA.

## Proyectos disponibles

| Proyecto | Descripción |
| --- | --- |
| [Smart Calculator Agent](Smart%20Calculator%20Agent/README.md) | Calculadora en lenguaje natural que utiliza herramientas en C# para resolver operaciones y encadenar cálculos. Integra Semantic Kernel y OpenRouter, y muestra los pasos ejecutados. |
| [Meteorological Assistant](Meteorological%20Assistant/README.md) | Asistente meteorológico que consulta Open-Meteo para obtener el tiempo actual y previsiones, comparar ciudades y ofrecer recomendaciones según las condiciones. Utiliza Semantic Kernel y OpenRouter. |
| [Personal Assistant with Memory](Personal%20Assistant%20with%20Memory/README.md) | Asistente personal que conserva conversaciones, propone recuerdos para su aprobación y recupera información por significado. Combina Microsoft Agent Framework y OpenRouter con PostgreSQL, pgvector y embeddings locales mediante Ollama. |

Cada proyecto incluye su propio README con los requisitos, las instrucciones de arranque, ejemplos de uso y pruebas.
